最近更新
Agent (智能体)
能自己拆任务、调工具、分几步把一件事做完的 AI,比"聊天机器人"进了一步。
微调 (Fine-tuning)
用你自己的少量数据,给通用大模型"补课",让它更懂你的行业。
大模型 (LLM)
用海量文字"喂"出来、能像人一样理解和生成语言的 AI,是近两年 AI 热潮的主角。
RAG (检索增强生成)
让大模型回答前先"翻你公司的资料库",再作答,防止它凭空胡编。
Token
AI 处理文字的"最小计量单位",也是你按用量付钱的方式(约 1 汉字 ≈ 1~2 Token,1 英文单词 ≈ 1~2 Token)。
训练与推理
训练 = 教模型(贵,要海量算力);推理 = 用模型(便宜,每次调用都有成本)。两者都吃 GPU。
GPU 云 / 算力租赁
在云端按小时/按卡租 GPU(英伟达或国产芯片),用来训练或跑大模型。
IaaS / PaaS / SaaS
云服务按"你管多少、云管多少"分三层:租服务器(IaaS)、租平台(PaaS)、租成品软件(SaaS)。
