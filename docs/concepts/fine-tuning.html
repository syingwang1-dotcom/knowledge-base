微调 (Fine-tuning)

收录于 2026-08-24 · 更新于 2026-08-24

一句话

用你自己的少量数据,给通用大模型"补课",让它更懂你的行业。

大白话解释

通用模型像名校通才,什么都会但不够精。微调就是拿你行业的几百上千条样本再教它一轮,让它开口就是行话、懂你们的黑话。

  • 比 RAG 更"深入骨子"(改的是模型本身),但更贵、更花时间;
  • 适合数据敏感、话术要高度定制、量大才划算的场景。

销售话术版

客户纠结"模型不懂我的行业",你给他两条路:

轻的用 RAG(快、便宜、随时换资料),重的用微调(准、贵、改模型本身)。根据你们的数据量和预算,我建议先 RAG 试点,见效了再考虑微调。

——给选择、给路径,而不是硬推,客户更信你。

备注

微调 + RAG 可以组合用:先微调教"腔调",再 RAG 查"事实"。
