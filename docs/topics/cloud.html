云计算

云分层、MaaS、GPU 云与私有化部署 · 共 4 条

GPU 云 / 算力租赁

在云端按小时/按卡租 GPU(英伟达或国产芯片),用来训练或跑大模型。

IaaS / PaaS / SaaS

云服务按"你管多少、云管多少"分三层:租服务器(IaaS)、租平台(PaaS)、租成品软件(SaaS)。

MaaS (模型即服务)

把大模型当"自来水"卖——不卖模型本身,按你的使用量(调用/Token)收费。

私有化部署 / 一体机

把模型装进客户自己的机房(或软硬件打包成一台"一体机"交货),数据不出门。
