## 一句话
AI 处理文字的"最小计量单位",也是你按用量付钱的方式(约 1 汉字 ≈ 1~2 Token,1 英文单词 ≈ 1~2 Token)。

## 大白话解释
模型不按"字数"认字,按 Token 认。就像电话按分钟计费、水按吨计费,大模型按 Token 计费。
- 你让它写 500 字,大约消耗 1000 Token;
- "上下文窗口"(它能记住多少对话)也用 Token 衡量,窗口越大,能塞进的话越多、越贵;
- 百度那篇财报里"百度搭子把 Token 消耗降低 75%",意思就是同样的活,花的钱只剩 1/4。

## 销售话术版
报价时客户要砍价,你拿 Token 拆账:
> 一次客服对话大约消耗 X Token,按你们每月业务量,成本大概这么多。Token 单价在降、用量在涨,总账划算。而且我们的优化能让同样的话,Token 消耗省 75%。

## 备注
Token 是成本谈判的货币单位,做销售必须会换算"业务量 → Token → 钱"。
