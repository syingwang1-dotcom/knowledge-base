## 一句话
云服务按"你管多少、云管多少"分三层:租服务器(IaaS)、租平台(PaaS)、租成品软件(SaaS)。

## 大白话解释
像租房:
- **IaaS**(基础设施即服务)= 毛坯房:只给你硬件(服务器、存储、网络),系统、软件、运维自己管;
- **PaaS**(平台即服务)= 精装房:连开发环境、数据库都配好,你只写业务;
- **SaaS**(软件即服务)= 酒店:啥都别管,入住即用,按年付钱。
- 大模型按 API 调用卖,本质也是一种"软件即服务"。

## 销售话术版
先问客户"你们有多少技术人员",再决定卖哪层:
> 你们 IT 团队强,我建议 IaaS + PaaS,便宜又灵活;团队小,直接上 SaaS,省运维。
卖错层是销售大忌——把 IaaS 卖给没 IT 的客户,等于让他自己盖毛坯房。

## 备注
百度智能云、阿里云、华为云都是"全栈"(三层都做),但靠 IaaS 起家、靠上层赚钱。
